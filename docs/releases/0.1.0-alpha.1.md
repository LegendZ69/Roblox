# Driftwood Isles 0.1.0-alpha.1

The first versioned alpha of the cooperative island builder is available for Roblox Studio.

Gather wood, build a campfire and bridge, gather stone, and restore the beacon. Invite players in the same server to help with a shared stockpile, then complete a timed storm repair challenge. Resources, buildings, tutorial progress, reward receipts, and cooldowns belong to the island owner and can be saved.

Download `DriftwoodIsles-0.1.0-alpha.1.rbxlx`, or the matching ZIP for the place plus setup and validation guides. Open the place in Roblox Studio on Windows or macOS and press **Play** to generate the islands. Studio defaults to labeled session-only saves; the README explains separate persistent test saves.

Cloud validation covers 41 behavior groups across island rules, persistence, and the production multiplayer coordinator; Luau compilation; strict core analysis; formatting; and verification of shipped script sources, service placement, and configured properties. The release workflow also checks packaging and publication failure behavior before uploading files. `release-manifest.json` identifies the exact source commit and pinned tools; `SHA256SUMS` verifies the downloadable files.
