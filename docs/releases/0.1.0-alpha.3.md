# Driftwood Isles 0.1.0-alpha.3

Milestones 2–5: progression acceptance, cooperative storm acceptance, permission-aware first-session guidance, and a source-bound alpha handoff.

## Player-facing fixes

- Visitors watching a storm retain read-only guidance instead of receiving repair instructions.
- Paused host islands explain recovery to owners and helpers before showing gameplay objectives.
- Studio labels preserve loading, saving, and recovery information.
- Beacon objectives show the exact remaining wood and stone; completed tutorials stay completed after reload.
- Storm failure and success have distinct captions. Countdown expiry waits for the server's confirmed outcome.
- Longer objective directions can grow inside the scrolling panel.

The bridge/beacon and storm implementations already existed. This version adds explicit production-interface acceptance scenarios for every saved construction checkpoint, shared construction with two helpers, all four supported storm crew sizes, retries, cancellation, and reward-save recovery.

## Cloud handoff

The full validation pipeline includes Luau compilation, strict pure-module analysis, formatting, 71 behavior groups across seven Luau suites, Rojo place construction, exact-source verification, and 65 Python tooling tests. Empty Python test discovery fails on every supported interpreter version. The pipeline writes `cloud-validation.json` only after successful completion with unchanged inputs.

The setup ZIP includes that report and the milestone acceptance guide. Packaging binds every reported input to the release commit and rejects a missing/stale report or a changed place. The report is an execution record to inspect alongside the matching GitHub Actions run, not a signed test attestation.

## Still pending

This is a GitHub alpha prerelease, not a published Roblox experience. Studio Script Analysis, real multiplayer clients, world rendering/collisions, DataStore networking, desktop/touch layouts, first-session pacing, and actual-phone performance remain unverified. Follow the included Studio checklist before external playtesting. Abrupt server failure can still lose progress since the last confirmed save.
