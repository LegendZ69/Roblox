# Domain glossary

- **Island**: One player-owned persistent outpost with its own stockpile, projects, and event progress.
- **Owner**: The player whose UserId identifies the island’s saved record; must be online for it to accept actions.
- **Helper**: A player who accepts the owner’s temporary invitation to gather and construct on that island.
- **Visitor**: A player viewing another island without permission to modify it.
- **Stockpile**: The island’s shared wood and stone, never a player-to-player transferable inventory.
- **Project**: One predefined construction at a fixed site: campfire, bridge, or beacon.
- **Resource node**: An authored tree or stone deposit that yields supplies subject to server cooldowns.
- **Storm**: A timed cooperative repair challenge unlocked by the beacon.
- **Session lease**: Exclusive, expiring permission for one server to write an island record.
- **Session-only mode**: Deliberate Studio mode that keeps data in memory for the running test server.
